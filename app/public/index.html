数据口径说明
阿里云百炼：“账期”使用费用中心月度实例账单（DescribeInstanceBill · MONTHLY），“日期”使用按天账单（DAILY），金额与阿里云控制台一致；账单实例ID格式 ApiKeyID;业务空间ID;模型;计费项;[调用渠道];[免费额度用完即停]，ApiKeyID 为空表示控制台体验、订阅套餐、Batch 等非 API Key 调用。
腾讯云 TokenHub：账单来自计费中心账单明细（DescribeBillDetail，按资源出账，不含 API Key）。Key 级费用 = 当日该模型同一计费项（输入 / 缓存命中 / 输出）的真实账单金额 × 该 Key 在当日该模型对应 Token 用量（TokenHub 用量统计）中的占比，标记为“分摊”；资源本身为 API Key 时直接归属。合计金额与腾讯云账单完全一致。缺少费用权限时可按目录价“估算”。
自然日按北京时间划分。应付金额 = 原价 − 优惠 − 优惠券抵扣（税前）；可在筛选栏切换为原价或优惠后金额。账单相对实际调用约延迟数小时，当月数据会随同步持续更新，次月 3 日后出账为准。 环比：历史账期对比上月全月，当月对比上月同期（相同天数），按日期查询对比上一个等长周期。
费用口径：原价（目录价）− 折扣 = 优惠后金额；优惠后金额 − 优惠券 / 代金券 / 储值卡抵扣 = 应付金额（默认，与费用中心一致）。切换口径后会保存在本浏览器并用于所有页面，筛选栏下方会提示当前不是“应付金额”。
按账期与按日期：同一自然月按账期（月账单）与按日期（日账单）查询，原价、折扣、优惠券与应付金额完全一致；但优惠券与折扣按云厂商实际抵扣的日期计入（例如优惠券会从某天起连续抵扣直到用完，当天应付可能为 0），只查询月内部分日期时，金额不会按天均摊。费用异常判断按原价进行，不受优惠抵扣影响。

修改密码

为保障账号安全，首次登录或密码被重置后需先设置新密码。
至少 10 位，需同时包含字母和数字，且不能包含用户名。修改后其他设备上的登录会话将失效。
